# Assets v2.1.0

This directory contains pre-rendered media templates and audio files for the Kink Drone v2.1.0.

## 1. Spiral Templates (assets/spiral_templates/)
These are 128x128 monochrome patterns for the local OLED display.
- `rainbow_v2.1.0.gif`: Smooth color/gray transitions.
- `grid_v2.1.0.mp4`: Geometric grid patterns for visual focus.
- `fractal_v2.1.0.gif`: Recursive patterns for long-term focus.

## 2. Audio (assets/audio/)
These are binaural tone WAV files for the 3.5mm audio interface.
- `binaural_4hz_v2.1.0.wav`: Deep relaxation frequency.
- `binaural_8hz_v2.1.0.wav`: Alpha-state frequency.
- `binaural_12hz_v2.1.0.wav`: Alert alpha-state frequency.

## 3. QR Codes (assets/qr_codes/)
Pre-generated QR codes linking to:
- `safety_briefing_qr.png`: Link to the safety PDF.
- `calibration_protocol_qr.png`: Link to the MD calibration document.
- `firmware_manifest_qr.png`: Link to the JSON firmware manifest.

**Note**: All media is stored and played locally on the device or companion app. No media is streamed from the internet.
